# 2026-11-24 追加

## 图像导出（PNG）

- 工具栏「保存图像」把视口 `PixelMap` 用 `ImagePacker` 打包为 PNG，写入应用沙箱
  `cx_frame.png`（设备读数 `png=93742` 字节），启动时也会自动保存一次
- 对应原版 ChimeraX 的 "save image" 动作，且不依赖被冻结的 `save` 命令路径

## 模型显示/隐藏联动

- 「隐藏/显示」按钮切换所有原子模型的 `model.display`，切换后刷新模型面板并重渲染
- 设备读数 `display=off|models=6|changed=6`，对应原版 Model Panel 的勾选框
