## 二、未完成项与精确卡点

### 1. ChimeraX 官方渲染器（需一次完整实现）

- 现状：EGL 上下文、PyOpenGL 对齐、ES3 入口点、着色器编译全部打通；**PyOpenGL 在本平台
  的包装函数静默返回 0**（裸 ctypes 对照正常）
- 已完成的自建替代：`chimerax/graphics/_cxgl.py` + 从 NDK 头文件生成的 **82 条精确签名**
  （`tools/generate_cxgl_signatures.py`），并有 **117 个单测**含"89 个调用点全部可达"的断言
- 卡点：把该层替换 PyOpenGL 后应用**进程直接退出**（非 Python 异常），四次尝试一致。
  根因是渲染器调用序还依赖 PyOpenGL 的隐式语义（`*v` 接受列表、`glBufferData` size 推导、
  `glVertexAttribPointer` 偏移指针化等），需要**逐函数完整实现**

### 2. Qt 原生窗口

- 运行时拒绝对 Qt 插件所需的 JS 表达式求值（`LocalStorage.makeNewLocalStorage()`）
- 四条交底路径的设备日志封存在 `docs/qt-status-2026-11-18-final.md`

### 3. bundle 覆盖度

- 已接入 8 类：core/commands/session/toolshed、atomic/atomstruct、pdb/mmcif/io/open、
  list_info、items_inspection、sdf/mol2、zone、label、mouse_modes
- `zone` 可注册但执行需 `chimerax.map` 的 C++ 扩展（`combine/fitting/interpolate`），尚未交叉编译

## 三、复现命令

```bash
# 1. 交叉编译 CPython/numpy 依赖（一次性）
python3 tools/build_cpython_harmony.py
python3 tools/build_numpy_harmony.py
python3 tools/build_tinyarray_harmony.py

# 2. 核心 C++ 支持库与扩展
python3 tools/build_atomic_shared_lib_harmony.py
python3 tools/build_atomic_ext_harmony.py
python3 tools/build_graphics_ext_harmony.py
python3 tools/build_cython_modules_harmony.py
python3 tools/build_pdb_ext_harmony.py

# 3. 暂存 ChimeraX Python 树（含 _atomspec 生成、grako 运行时、bundle_info.xml）
python3 tools/stage_chimerax_python.py

# 4. 生成 GL 签名表（可选，渲染线工作用）
python3 tools/generate_cxgl_signatures.py

# 5. 打包 payload 与 HAP，然后设备验收
python3 tools/package_app_runtime.py
python3 tools/build_hap.py
python3 tools/device_app_check.py
```
